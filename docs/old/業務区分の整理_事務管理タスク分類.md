# 業務区分の整理（実施業務 ＝ フェーズ ＝ 実務タブ ＝ 事務管理タスク一覧のタブ）

## 1. いまの系統

```
①受注区分（手続き区分）      オーダーシート「受注内容」で選ぶ
        ↓ 選ぶと初期セットされる
②実施業務                    オーダーシート／面談シートで選ぶ（戸籍・不動産調査 等）
        ↓ そのままコピーされる
③タスクのフェーズ(phase)      タスク一括生成・タスク追加で入る値
        ↓ GYOMU_TAB で対応づけ
④案件詳細の実務タブ           相続人調査／財産調査／遺産分割／相続登記／解約手続 …
```

②③④は**同じ「業務」を指す**のに、名前が3か所でずれています。

| 内部の業務名（③フェーズ） | ②実施業務の表示名 | ④実務タブ名 |
|---|---|---|
| 戸籍 | 戸籍 | 相続人調査 |
| 相関図 | 相関図 | 相続人調査 |
| 法定相続情報取得 | 法定相続情報取得 | 法定相続一覧図 |
| 不動産 | **不動産調査** | 財産調査 |
| 金融資産 | **金融資産調査** | 財産調査 |
| 目録 | （選択肢なし） | 財産調査 |
| 協議書 | 協議書 | 遺産分割 |
| 登記 | 登記 | 相続登記 |
| 解約 | 解約 | 解約手続 |
| 手紙 | 手紙 | 手紙 |
| 精算書作成／指図書作成 | **遺産承継**（2つまとめて） | 遺産承継 |
| 契約書作成 | **契約書** | 契約書作成 |
| 遺言作成／信託契約書作成／放棄手続き／調停手続き／検認手続き／後見手続き／執行通知 | 同名 | 遺言／信託契約／相続放棄／調停／遺言検認／成年後見／執行通知 |
| 経理／相続税（横断） | — | — |

さらにこの上に **工程（KOTEI）** という括りがあり、事務管理タスク一覧はそれで絞り込ませていました。
実務と対応しない中間レイヤーだったので、**工程は事務管理タスク一覧から外します**（相関図は廃止済み）。

---

## 2. 新しい定義

事務管理タスク一覧のタブは **④実務タブ名を基準**にします。財産調査だけは実務が別作業なので、
②実施業務の名前（不動産調査／金融資産調査）で2つに割ります。

### 事務管理タスク一覧のタブ（左から）

| # | タブ名 | 入るフェーズ（業務） | 主なタスク |
|---|---|---|---|
| 1 | **相続人調査** | 戸籍 | 戸籍請求／戸籍読込 |
| 2 | **不動産調査** | 不動産 | 名寄帳・評価証明を請求／読込、登記・公図・地積を請求／読込 |
| 3 | **金融資産調査** | 金融資産 | 凍結してよいか確認／凍結依頼／資料請求／資料読込 |
| 4 | **解約手続** | 解約 | 預貯金の解約／証券の移管・売却／自動車名義変更 |
| 5 | **相続登記** | 登記 | 識別情報通知の受領／不動産登記簿の受領<br>※申請・権利書の製本・登記簿の申請は相続登記チームの持ち場 |
| 6 | **各種作成物** | 相関図・目録・協議書 | 相関図作成／財産目録作成／遺産分割協議書の作成 |
| 7 | **納品** | 納品（新設） | 納品書類一式の作成／原本の返却準備／発送 |
| 8 | **その他** | その他（新設） | どの業務にも属さない任意タスク |

名前の対応：**相続人調査・相続登記・解約手続・納品 は実務タブ名と同じ**。
**不動産調査・金融資産調査 は実施業務の名前と同じ**。**各種作成物・その他 は今回の新規定義**。

### 業務区分（フェーズ）に足すもの

| 追加する業務 | 実務タブ | 理由 |
|---|---|---|
| **納品** | 納品 | 実務タブに納品はあるのに業務区分が無く、納品作業のタスクを置く場所がなかった |
| **その他** | （なし） | どの業務にも属さないタスクの置き場。タスク追加のフェーズ選択にも出す |

既存の「納品書類一式作成」（いまは経理業務）は **納品** に移します。

## 3. 管理担当の仕事に寄せる業務

次の5つは管理担当がやる仕事なので、**一括生成したときに管理担当タスクとして作る**ようにします
（＝事務管理タスク一覧には出ず、管理担当のマイページ「タスク」タブに出る）。

| 業務 | 実務タブ |
|---|---|
| 手紙 | 手紙 |
| 執行通知 | 執行通知 |
| 契約書作成 | 契約書作成 |
| 放棄手続き | 相続放棄 |
| 相続税 | （横断） |

これで管理担当タスクになる業務は次のとおりです。

> 遺言作成／信託契約書作成／検認手続き／後見手続き／調停手続き／精算書作成／指図書作成／
> 法定相続情報取得／他事業者紹介 ＋ **手紙／執行通知／契約書作成／放棄手続き／相続税**

事務管理タスクとして残るのは **戸籍・相関図・不動産・金融資産・目録・協議書・登記・解約・納品・その他** の10業務。
上の8タブでちょうど全部が拾えます。

## 4. 変わること

| 画面 | 変更 |
|---|---|
| 事務管理タスク一覧 | 工程の絞り込み → 8タブに置き換え。工程・業務区分のバッジ列も不要になるので外す |
| タスク追加（事務管理タスク） | フェーズの選択肢に **納品／その他** を追加 |
| タスク一括生成 | 手紙・執行通知・契約書作成・放棄手続き・相続税 を管理担当タスクとして生成 |
| 実務タブ | 変更なし（タブ名はそのまま使う） |
| オーダーシートの実施業務 | 変更なし |

## 5. 決めきれていない点

- **経理業務**（分配金計算書作成／報酬請求書作成／入金確認／分配金送金実行／案件クローズ処理）は
  いま一括生成の対象外です。誰の持ち場にするかは別途。
- **目録（財産目録）** は実施業務の選択肢に無く、一括生成でも作られません。
  各種作成物タブに置く前提なら、実施業務に「財産目録」を足すか、タスクを手で足す運用になります。
