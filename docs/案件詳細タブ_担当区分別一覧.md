# 案件詳細タブ 担当区分 × 案件ステータス 一覧

いま何がどう出ているかの棚卸し。判定は次の2か所にある。

- `src/lib/caseTabs.ts` … ステータスで決まる表示（`getCaseTabVisibility`）
- `src/components/features/cases/CaseDetailClient.tsx` … 管理担当だけ別の固定セット（`MANAGER_TABS`）

## 0. 先に結論（3点）

1. **受注担当・事務管理担当・相続登記チームは、まったく同じタブが出る。** 担当区分での出し分けは管理担当にしか無い。
   相続登記チームも、相続人調査から請求まで全部見えている。
2. **管理担当だけステータスに関係なく固定。** 面談設定済の案件でも「請求」「納品」タブが出る。
3. 到着物 / 案件フォルダ / 書類作成 はタブではなく**ヘッダーのボタン**。管理担当のビューには出ない。

---

## 1. 受注担当 ／ 事務管理担当 ／ 相続登記チーム（3者とも同じ）

### 受注前

| タブ | 面談設定済 | 検討中 | 依頼確定待ち |
|---|:-:|:-:|:-:|
| オーダーシート | − | ○ | ○ |
| 案件進捗 | ○ | − | − |
| 契約手続き | − | ○ | ○ |
| 依頼者連絡 | ○ | ○ | ○ |
| 請求 | − | ○ | ○ |
| タスク | ○ | **−** | ○ |
| 案件情報（担当者・案件管理・面談情報） | 面談情報のみ | ○ | ○ |
| 〔ヘッダー〕到着物 / 案件フォルダ / 書類作成 | ○ | ○ | ○ |

> 検討中だけタスクタブが出ない（依頼確定待ちから出る）。

### 受注後（受注 / 戻り受注 / 作業着手準備）

3ステータスとも**依頼確定待ちと同じ**。

> オーダーシート ／ 契約手続き ／ 請求 ／ 依頼者連絡 ／ タスク ／ 案件情報 ＋ ヘッダーの3つ

実務タブ（相続人調査・財産調査 等）は**まだ出ない**。作業進行中になった時点で解禁される。

### 作業着手後（作業進行中 / 業務完了 / 納品完了）

実務フルセット。並びは左から：

| # | タブ | 出る条件 |
|---|---|---|

| 5 | 契約手続き | 常時（**折りたたみ**＝末尾の「その他」） |
| 6 | 依頼者連絡 | 常時 |
| 7 | 相続人調査 | 実施業務に 戸籍／相関図 があるとき |
| 8 | 財産調査 | 実施業務に 不動産／金融資産／目録 があるとき |
| 9 | 他事業者紹介 | 常時 |

## 2. 管理担当（manager / sub_manager）

**ステータスに関係なく固定。** 受注前でも作業着手後でも下記が出る。

| # | タブ | 備考 |
|---|---|---|
| 1 | オーダーシート | |
| 2 | 案件報告 | 進捗サマリーはこの中 |
| 3 | 依頼者連絡 | |
| 4 | 信託契約 / 遺言 / 遺言検認 / 成年後見 / 調停 / 遺産承継 / 法定相続一覧図 | **管理担当が担う実務タブだけ**。実施業務にあるものだけ出る |
| 5 | 他事業者紹介 | |
| 6 | 請求 | |
| 7 | 納品 | |
| 8 | タスク | |
| 9 | 案件情報（担当者・案件管理・面談情報） | |

**出ないもの**：相続人調査／財産調査／遺産分割／相続登記／解約手続（事務管理の持ち場）、
案件進捗、契約手続き、到着物、案件フォルダ、書類作成。

## 4. 気になる点（要判断）

| # | 内容 |
|---|---|
| A | **相続登記チームに全タブが見えている**。相続登記・タスク・到着物あたりに絞る余地がある |
| B | **事務管理担当にも全タブが見えている**。管理担当だけ絞っているのと非対称 |
| C | **管理担当のタブがステータス非依存**。面談設定済の案件でも請求・納品が出る |
| D | 管理担当に **到着物・案件フォルダ・書類作成** が無い。受信の確定（W-Check）は管理担当の仕事なので、到着物は必要かもしれない |
| E | 検討中だけタスクタブが出ない |
