## G1. 受注/戻り受注化時の「割振り依頼」

- `検討中`／`依頼確定待ち` → **受注/戻り受注** にステータス変更したとき、「管理担当に割振りを依頼」が出る。
- 割振り担当の選択を **菅家しずく／上田拓海のどちらか**、または **その他を検索して指定** する形式にする。
- 動作は **アラート（通知）を飛ばすだけ**（割振り担当が後で管理担当をアサイン）。
- 狙い：受注になった時点で管理担当をアサイン → フォロー体制を作る。
- 既存 `AssignRequestModal`（is_dispatcher＝菅家/上田）をこの仕様に合わせて調整。

## G2. 受注 → 作業着手準備 ナビ（4ゲートに再定義）

現状（オーダーシート作成／契約書類受領／基本料金 or 料金表画像）を下記4つに：

| ゲート | 完了条件 |
|---|---|
| オーダーシート作成 | オーダーシートが作成されたら完了 |
| 管理担当アサイン | 受注系ステータス化 → 割振り担当へ通知 → 割振り担当が管理担当を案件担当者に設定したら完了 |
| 契約書類の受領 | 契約書類を **全部** 受領したら完了 |
| 料金表入力・前受金請求書の発行 | **前受金請求書を発行** したら完了 |

※ 現在「管理担当アサイン」は次のナビ(G5)にあるが、**こちら(受注→準備)へ移動**。

## G3. 契約手続きタブ（契約書類の受領）— ⚠️バグ＆再設計

**正しい挙動（維持）**：面談時に名寄帳・固定資産評価証明を「受領✓」すると契約手続きに表示され受領済になる。

**直すこと：**
- 「契約書類4点をまとめて追加」ボタンは **不要 → 削除**。
- 代わりに **デフォルトで5点を常時表示** し、各行で受領状況を選べるように：
  - 契約書 / 料金表 / 委任状 / 本人確認書類 / 印鑑証明
- ⚠️**バグ1**：受領状況を **1つでも「その場で受領」** にすると、残りが未入力でも **ナビが完了扱い** になる（＝全部受領で初めて完了にすべき）。
- ⚠️**バグ2**：受領状況を「その場で受領」→「後日郵送」に変えても、**受信ステータスが受信済→未受信に戻らない**。

→ ナビ(G2)の「契約書類の受領」完了条件は「**この5点＋面談時受領分が全部受領**」で判定する。

## G5. 作業着手準備 → 作業進行中 ナビ（再定義）

- 文言：「**対応中** に進むための残り対応」→「**作業進行中** に進むために」。
- 4ゲート：

| ゲート | 完了条件 / ナビ線 |
|---|---|
| オーダーシート最終化 | オーダーシートで**最終化ボタンを管理が押す**。**オーダーシートタブにナビ線**を伸ばす |
| タスク出し | **タスクタブにナビ線**。管理担当が一括生成。※作業進行中より前は**事務管理タスクも見えてよい**（今は隠れている）。※作業進行中にした時の「タスクを設定してください」ポップアップは**削除** |
| 前受金の入金 | **請求タブで入金ステータス＝入金** になったら自動完了 |
| ファイル化 | ❓ **このナビ上でも「済」にできるようにする？**（下記参照） |

**現状のファイル化フロー**：ファイル化以外が完了 → 事務管理ダッシュボードに新規レコード挿入 → 事務管理担当がファイル化を「済」→「案件着手」ボタンで**作業進行中**へ。作業進行中になって初めて、その案件の事務管理タスクが事務管理タスク一覧に表示される。

❓**要決定**：ファイル化をこのナビ上でも済にできるようにするか（事務管理ダッシュボードと二重導線にするか）。

## G6. タスク機能

### 6-1 一括生成時のフラグ
- 現状：着手OK／受領次第OK をある程度自動付与。
- 変更：**被相続人の戸籍請求タスクだけ着手OK**、それ以外は**何もフラグを付けない**。
- 一括生成時は**優先度＝全部「普通」**（デフォルト）。

### 6-2 完了モーダル
- ⚠️「次に着手できそうなタスク候補を**自動選択**」機能は **無し** に。
- 完了モーダル／タスク詳細の「**管理担当にヘルプ**」→ 押すと **報連相モーダルが開き**、報連相テーブルに通知を挿入できるように。
- 戸籍読込で1個の戸籍から複数相続人分が判明 → **複数タスクをまとめて完了**できるように（他の相続人の戸籍請求/読込タスクが不要になるケース）。

### 6-3 個別タスク追加
- **優先度を選択**：普通 / 急ぎ / 超急ぎ。
- 生成時に **着手OK / 受領次第OK を選べる**ように。

### 6-4 タスクタブ（一覧）で調整
- 方針：一括生成後、**案件詳細のタスクタブで優先度・着手OKフラグを調整**する。
- 現状：一覧で着手OKフラグは変更できるが**優先度は変更できない → できるように**。

### 6-5 事務管理タスク一覧の並び・色
- **優先度が高い順**に上から並べる。
- **急ぎ＝黄色 / 超急ぎ＝赤** で**行ごと色付け**。
