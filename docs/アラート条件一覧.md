# アラート条件 一覧

システムが自動で出すアラートの全条件。2026-08-08 時点の実装に一致。

**営業日の定義**：日曜と祝日を除く日。**土曜は営業日**。祝日は法律どおり計算（`src/lib/holidays.ts`）。

アラートには 3つの出どころがあり、出る場所が違う。

| 出どころ | 実装 | 出る場所 |
|---|---|---|
| ① 請求（レコード由来） | `billOverdueSeverity` | マイページの要確認／要注意バナー → 要対応一覧「入金期日超過」 |
| ② タスク（レコード由来） | `overdueSeverity` | 同上 → 要対応一覧「タスク期日超過」 |
| ③ 案件状態（計算） | `caseStateAlerts.ts` | 同上 → 要対応一覧「案件アラート」 |
| ④ 案件チップ（計算） | `alerts.ts` | 案件詳細ヘッダーのバッジ／案件色 |

---

## ① 入金期日超過（請求）

対象：`invoices` のうち ステータス＝入金待ち。起点＝入金期日。

| 条件 | 重要度 |
|---|---|
| 入金期日を **3営業日** 超過 | 要確認（黄） |
| 入金期日を **5営業日** 超過 | 要注意（赤） |

## ② タスク期日超過

対象：未完了タスク（完了・キャンセルを除く）。起点＝タスクの期日。

| 条件 | 重要度 |
|---|---|
| 期日を **5営業日** 超過 | 要確認（黄） |
| 期日から **14日**（暦日）経過 | 要注意（赤） |
| 優先度が **超急ぎ** の未完了タスク | 要注意（赤）※期日前でも出る |
| 期日超過が 1〜4営業日 | 軽微（バナーには出ない） |

案件が要対応一覧に出るのは、その案件に要確認以上のタスクが1件でもあるとき。一覧では
その案件の超過タスクを全件（軽微も含めて）並べる。

## ③ 案件アラート

| アラート | 対象ステータス | 条件 | 起点 | 重要度 |
|---|---|---|---|---|
| 管理担当 未アサイン | 受注／戻り受注／作業着手準備 | 管理担当が未設定のまま **2営業日** 経過 | 受注日 | 要注意（赤） |
| オーダーシート未完成 | 同上 | 完成していないまま **3営業日** 経過 | 受注日 | 要確認（黄） |
| オーダーシート未完成 | 同上 | 完成していないまま **5営業日** 経過 | 受注日 | 要注意（赤） |
| 到着物あり（未開封） | 問わない | 受注/管理宛の郵送物一式が到着連絡済みで未開封 | 到着連絡日 | 要確認（黄） |
| 案件報告：至急 | 問わない | 状態＝「至急！！」の案件報告が未確認 | 報告日 | 要注意（赤） |

- 管理担当 未アサインは「この案件には管理担当を割り振らない」にした案件では出ない。
- 対象者：管理担当未アサイン・オーダーシート未完成・案件報告は**受注担当**の案件。
  到着物は**受注担当または管理担当**の案件。

## ④ 案件詳細ヘッダーのチップ（案件色）

案件色は最大深刻度で決まる。**紫 ＞ 赤 ＞ 黄 ＞ 青**。

| チップ | 条件 | 深刻度 |
|---|---|---|
| クレーム | クレームありフラグ かつ 進行中の案件 | 紫 |
| タスク期限超過 | 期限超過の未完了タスクが1件以上 | 赤 |
| 管理担当 未アサイン | 受注〜作業着手準備 かつ 未設定 かつ 受注から2営業日超過 | 赤 |
| 前受金 未請求 | 受注〜作業着手準備 かつ 請求書未発行 かつ 受注から5営業日超過 | 赤 |
| 前受金 未入金 | 前受金請求書が 作成済 または 入金待ち | 赤 |
| 完了予定日 超過 | 完了予定日を過ぎている（完了・失注を除く） | 赤 |
| 未対応 10営業日超 | 最後に案件を開いてから10営業日超過 | 赤 |
| 週次報告の漏れ | 直近7日に確認済の進捗報告がない | 黄 |
| 面談メモ未記載 | 面談日を過ぎたのに面談実施日が未入力 | 黄 |
| 回答予定日 間近／超過 | お客様回答予定日が2日以内 or 超過 かつ 確認タスク未完了 | 黄 |
| 未対応 5営業日超 | 最後に案件を開いてから5営業日超過 | 黄 |

「進行中の案件」＝ 受注／戻り受注／作業着手準備／対応中。
