# 遺産承継 シミュレーションシナリオ（面談シート → 納品完了）

面談シート作成から納品完了まで、**受注担当 → 割振り担当 → 管理担当 → 事務管理 → 相続登記チーム → 経理** のバトンを1本通しで確認するための台本です。
面談シート・面談結果登録・オーダーシートは、**備考欄・メモ欄まで全部埋まる**ように入力値を用意しています。上から順にそのまま入れてください。

- 受注区分：**遺産承継**（精算書作成＋指図書作成を含む包括代行）
- 通す工程：相続人調査 → 財産調査 → 遺産分割 → 相続登記 → 解約手続 → 経理 → 精算・指図 → 請求 → 納品
- 請求パターン：**①段階請求（前受金 → 確定請求 → 立替実費）**
