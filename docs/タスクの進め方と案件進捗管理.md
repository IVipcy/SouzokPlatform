# タスクの進め方と、案件進捗管理（AI集計）

> 「オーダーシート → タスク／実務タブ自動生成 → タスクを回す → 実施結果をAIが集計して進捗にする」までの一連の考え方。
> 説明会・マニュアルの土台に。図は別途スライド化予定。

---

## 1. タスクと実務タブは、オーダーシートから自動で用意される

- **オーダーシートを元に、案件に必要なタスクが自動作成**される。
- 同時に、**実務タブ（財産調査・目録・請求 等）も自動で用意**される（作業する画面）。
- ＝ 担当者は「何のタスクを作るか」をゼロから考えなくてよい。**必要なぶんが最初から並ぶ**。

---

## 2. タスクの進め方（この4ステップを回す）

| # | ステップ | 内容 |
|---|---|---|
| 1 | **一覧に表示** | 事務管理タスク一覧に、**優先度（普通／急ぎ／超急ぎ）と着手OKフラグ**の順で並ぶ |
| 2 | **作業＋進捗記録** | タスク詳細を開き、**実務タブを見ながら**詳細作業の進捗を記録する |
| 3 | **完了：実施結果＋次を選択** | 完了時に**実施結果を記録**し、続けて**次に着手OKなタスクを選ぶ** |
| 4 | **次が一覧に現れる** | 選んだタスクが**着手OK**になり、一覧の上位に表示 → 1へ戻る |

- **↻ 1〜4を繰り返す**ことで、案件が前に進む。
- **迷ったら相談**：次に何をすればいいか／進め方が分からないときは、その場で**管理担当に相談**（報連相・ヘルプ）。ボールを一人で抱えない。

### フラグの意味（再掲）
- **着手OK**：いま着手してよいタスク。一覧に出る。
- **受領次第OK**：到着受信簿で書類が紐づくと、自動で着手OKに切り替わる。
- **優先度**：普通／急ぎ／超急ぎ。高い順に上から表示（急ぎ=黄・超急ぎ=赤）。

---

## 3. 案件進捗管理 — 実施結果をAIが集計してまとめる

- 各タスクの完了時に入れた**実施結果が案件に蓄積**される。
- それを**AIが集計 → 案件進捗サマリー**として自動でまとめる。
- ＝ 管理担当は、細かいタスクを一つずつ追わなくても、**「今どこまで進んだか」を一目で把握**できる。
- 分業（事務管理が実務、管理担当が進捗把握）が、この仕組みで成立する。

```
オーダーシート ─自動─▶ タスク一式 ＋ 実務タブ
                         │
        ┌────────────────┘
        ▼
 ① 一覧に表示（優先度・着手OK順）
        ▼
 ② タスク詳細で作業＋進捗記録（実務タブを見ながら）
        ▼
 ③ 完了：実施結果＋次の着手OKを選択
        ▼
 ④ 次のタスクが一覧トップに ──╮
        ▲                    │  ↻ 繰り返し
        ╰────────────────────╯
   （迷ったら → 管理担当に相談）

  各タスクの実施結果 ─蓄積─▶ AIが集計 ─▶ 案件進捗サマリー
```
